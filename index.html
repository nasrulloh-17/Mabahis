Panduan Implementasi Lengkap

Cara Kerja Website Statis + Google Form + Spreadsheet + Email Otomatis

Anda tidak perlu menyewa server backend atau mengatur SMTP secara manual. Google menyediakan Google Forms, Google Sheets, dan Google Apps Script yang bekerja otomatis di awan secara gratis.

Pilihan 1 · Paling Cepat (Tanpa Coding Server)

Google Form Resmi + Trigger Apps Script

  1. Buat 2 (atau lebih) formulir di forms.google.com dengan kolom wajib Alamat Email dan Nama Lengkap.
  2. Di setiap Google Form, buka Responses → Link to Sheets → Select existing spreadsheet, lalu pilih 1 file Google Spreadsheet yang sama. Google otomatis membuat tab terpisah (Form Responses 1, Form Responses 2, dst).
  3. Di Google Spreadsheet tersebut, klik Extensions → Apps Script, lalu tempel Skrip A di bawah (sudah mendukung multi-tab).
  4. Buka menu Triggers (ikon jam) → Add Trigger, pilih fungsi kirimEmailDariGoogleForm dengan event On form submit. Cukup 1 trigger untuk semua tab!
  5. Salin masing-masing tautan Google Form Anda lalu tempelkan di menu Hubungkan Google pada website ini.
Pilihan 2 · Tampilan Menyatu Penuh

Formulir HTML Website → Apps Script Web App

  1. Buat 1 Google Spreadsheet saja. Skrip B di bawah akan otomatis membuatkan tab berbeda untuk setiap formulir berdasarkan nama formulirnya.
  2. Buka Extensions → Apps Script, tempel Skrip B di bawah ini, lalu simpan.
  3. Klik Deploy → New deployment → Web app. Atur Execute as: Me dan Who has access: Anyone.
  4. Salin Web App URL (https://script.google.com/macros/s/.../exec) lalu tempel di menu Hubungkan Google.
  5. Setiap pengunjung mengisi salah satu formulir HTML di website ini, data masuk ke tab formulir terkait dan email konfirmasi otomatis terkirim dari akun Gmail Anda.
Dropdown Dinamis dari 1 Spreadsheet

Membaca Pilihan Pondok (DB ponpes) & Lomba (db lomba) Otomatis

Saat Skrip B (doGet + doPost) dipasang pada Google Spreadsheet Anda, website ini otomatis membaca daftar pondok dari sheet DB ponpes dan daftar cabang lomba dari sheet db lomba untuk mengisi pilihan dropdown pada formulir Pendaftaran Lomba MABAHIS. Ketika ada pondok baru mendaftar melalui Form Daftar Pondok, datanya langsung masuk ke sheet DB ponpes dan otomatis muncul di dropdown Form Lomba.

Izin Akses Saat Deploy Pertama Kali

Cara Menyetujui Layar "Google hasn't verified this app"

  1. Saat menekan Deploy, Google akan meminta izin karena skrip mengakses Spreadsheet dan mengirim email dari akun Anda (ini hanya muncul sekali untuk Anda sebagai pemilik, bukan untuk pengisi formulir).
  2. Klik Authorize access (Tinjau Izin), lalu pilih akun Google Anda.
  3. Jika muncul peringatan "Google hasn't verified this app", klik tulisan kecil Advanced (Lanjutan) di kiri bawah.
  4. Klik Go to [Nama Project] (unsafe) di bagian paling bawah. Langkah ini aman karena skrip berjalan di akun Google Anda sendiri.
  5. Klik Allow (Izinkan). URL Web App akan langsung muncul untuk disalin ke menu Hubungkan Google.

Pengaturan Koneksi Langsung

Hubungkan Google Spreadsheet & Google Form

Tempel URL Web App Google Apps Script atau tautan Google Form Anda di sini untuk menguji integrasi secara langsung dari browser. Pengaturan tersimpan di browser Anda dan dapat diekspor ke dalam file JavaScript saat siap diunggah ke hosting.

1. Koneksi Formulir HTML → Google Spreadsheet (Apps Script URL)

Jika Anda memakai Skrip B (doPost), masukkan URL Web App dari Google Apps Script di bawah ini. Saat terisi, seluruh formulir HTML di website ini akan mengirim data langsung ke Google Spreadsheet Anda dan memicu email konfirmasi otomatis.

2. Tautan Google Form Resmi per Program (Mode Embed)

Jika Anda memilih memakai Google Form langsung, masukkan tautan bagikan Google Form (misalnya https://docs.google.com/forms/d/e/.../viewform) untuk masing-masing formulir di bawah ini.

3. Ekspor Konfigurasi untuk Hosting Publik

Saat website statis ini diunggah ke hosting (GitHub Pages, Netlify, atau cPanel), salin potongan konfigurasi berikut ke bagian atas file main.js agar semua pengunjung langsung terhubung ke Google Spreadsheet Anda.

Catatan Perangkat Ini

Riwayat Pendaftaran & Pratinjau Email

Menampilkan seluruh formulir yang pernah Anda kirim dari browser ini beserta status pengiriman ke Google Spreadsheet dan salinan email konfirmasinya.
